# 造啥都行 · V0.6.0「断裂实验」

V0.6 在 V0.5 机械系统上加入更柔软的绳索、可断裂连接、全动态零件和主菜单。游戏仍是离线可运行的单页 PWA，不依赖 CDN 或外部素材。

## 新功能

### 柔性绳索

绳子现在由多段质量节点组成，不再是一根僵硬的直线约束。它会下垂、摆动、被动态结构带动。实验中会按真实模拟出的绳段位置绘制。

### 绳子与转轴会断

选中绳子或转轴，可以选择 **脆 / 标准 / 强韧** 三档强度。连接承受的约束力持续超过极限后：

- 绳子会从当前受力最大的绳段断开，两边绳段继续受物理影响。
- 转轴会失效，原来连接的物体立即分离并恢复相互碰撞。
- 画面会出现断裂碎屑和提示，音效开启时也有断裂声。
- 返回编辑后，断裂不会写回布局，可以继续调整并重跑。

### 所有实体零件都能动态

木板、弹簧、风扇、轮子都能在零件设置里切换 **固定 / 动态**。

- 动态木板：下落、碰撞、旋转。
- 动态弹簧：会被撞走，并在弹射时产生后坐。
- 动态风扇：会受重力与碰撞，风场跟随风扇一起移动和旋转。
- 动态轮子：滚动、碰撞，可连接转轴和电机；固定轮子不会滚动或驱动。

### 主菜单

打开游戏首先进入主菜单，可以继续上次实验、从第一关开始、直接选六个关卡、查看玩法和切换音效。点击左上角 Logo 可随时返回主菜单。

## 上传到 GitHub Pages

解压 PWA 包，把其中这些文件放到你当前 Pages 发布目录的顶层，并覆盖旧版同名文件：

- `index.html`
- `sw.js`
- `manifest.webmanifest`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

如果你的 Pages 从仓库根目录发布，就上传到根目录；如果从 `/docs` 发布，就放到 `/docs`。不要只上传 ZIP，也不要额外套一层文件夹。

等待 GitHub Pages 部署完成后，联网打开原地址。页头显示 **V0.6**，更多菜单里的更新检查显示 **V0.6.0**。已安装到 iPhone 主屏幕的 PWA 如果仍显示旧版，先用 Safari 联网访问一次原网址，再彻底关闭并重新打开主屏幕应用。

## 存档兼容

继续使用 `contraption-lab-v1`，V0.5 的六关布局、通关记录、动态木板、轮子、转轴与绳子都可继续载入。旧连接如果没有强度字段，会自动使用“标准”。旧轮子没有动态字段时仍按动态轮子处理。

## 物理范围

这是游戏化二维物理，不用于工程计算。柔性绳会有少量弹性伸长；绳子不与地形缠绕，也没有摩擦绕桩。可断裂阈值为玩法参数，不对应真实材料强度。极端重叠、非常短的连接或超高速装置仍可能产生夸张效果。
