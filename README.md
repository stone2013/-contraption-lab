# 造啥都行 · 手机适配版 0.2

在原来的三关物理建造 Demo 上改造的触屏版。保留木板、弹簧、风扇与固定机关物理，不是重做游戏，也没有改变关卡尺寸或重力。

## 试玩

**先点「看示例」，再点底部的「开始实验」。** 再点同一大按钮可暂停或继续；「返回编辑」保留布局和上一轮运动轨迹。

### 手机通过网页打开（推荐的试玩方式）

这是源码与 HTML 文件交付，**没有附带一个已经发布的在线网址**。聊天附件的文件预览不等于运行游戏网页。需要从能执行 JavaScript 的浏览器网页页面打开。

电脑已安装 Python 3 时，在本目录运行：

```sh
python3 serve.py --lan
```

Windows 可以使用：

```bat
py -3 serve.py --lan
```

电脑与手机连接同一 Wi-Fi。终端会显示形如 `http://192.168.1.8:8080` 的局域网地址，在手机浏览器里输入其中与电脑当前 Wi-Fi 对应的地址。不要在手机上输入 `localhost`。电脑保持开机，终端保持运行；结束后按 Ctrl+C 停止。端口冲突可加 `--port 8081`。

脚本仅提供临时目录中的单文件游戏，不暴露源码目录。它不是生产服务器，也不需要路由器端口转发。防火墙、访客网络隔离或不同 Wi-Fi 可能阻止局域网访问；仅在可信网络使用 `--lan`。不加 `--lan` 时只允许电脑本机访问。

### 单文件及网站部署

`contraption-lab-mobile.html` 把样式、物理、关卡与交互全部内嵌，没有 CDN、外部字体、外部图片、第三方统计或运行时依赖。

- 电脑可以用浏览器打开 HTML 文件。
- 手机的文件预览工具不一定运行 JavaScript；出现静态预览或源码时，请使用上面的网页地址方式。
- 发布到静态网站时，将这个文件命名为 `index.html` 即可。不需要构建服务器或数据库。
- “没有网络依赖”指文件内无外部资源；通过网址首次访问仍需连上网站或局域网服务器。本版没有实现 Service Worker 或 PWA 离线缓存，不能保证关闭网页后离线重开网站。

## 触屏操作

点下方零件，再点画布放置；也可将零件拖入画布。再点同类零件按钮，或点属性区的叉号，可以取消放置。点现有零件后拖动移动，拖动时出现局部放大镜（视口过短时不显示）。

双指捏合缩放、双指平移；放大后也可拖动空白处平移。右上角 `− / 全景 / +` 可不用手势控制视图。「全景」恢复全关卡视野。缩放仅改变镜头，不影响碰撞、重力或关卡数据。

选中零件后，用下方 `↶ 5° / ↷ 5°` 按钮旋转；长按连续旋转，一次长按对应一次撤销。长度、弹力或风力用滑块调整，垃圾桶删除所选零件。手机画布的选择区域和旋转手柄做了放大，精细操作时建议放大画布。

上方 `…` 菜单提供网格、轨迹和清空。清空后仍可撤销。右上角四向箭头切换专注视图；这是页面内的扩展视图，不依赖浏览器全屏或强制锁定屏幕方向。

竖屏采用「画布在上、零件在下、底部播放控制」；横屏采用左画布、右工具。极小横屏时工具区域可以单独滚动，播放控制不会随工具滚走。屏幕旋转不会重置布局；旋转时尚未结束的拖动会取消，防止坐标跳变。

桌面快捷键继续保留：`1/2/3` 选零件，`Q/E` 每次旋转 15°（Shift 为 5°），Delete 删除，空格开始/暂停，R 返回编辑，Ctrl/Command+Z 撤销。

## 数据与边界

本版只有一个运动小球和固定机关。没有新增轮子、绳索、动态结构倒塌、账号、排行榜或联网同步。

布局仍尝试保存在当前浏览器的 `localStorage`，沿用旧版存储键 `contraption-lab-v1`；只有在相同浏览器和相同源下才可能直接延续旧记录。文件换位置或网页换域名不会自动迁移存档。存储不可用时可临时玩；未选中时属性区会提示「临时会话」。清理浏览器数据可能删除布局。

切换到后台时暂停实验。编辑静止时不重复绘制整个画布，减少无用绘制。慢放只改变播放速度。声音默认关闭。

## 文件与构建

- `index.html`、`styles.css`、`app.js`：页面、响应式布局、输入交互。
- `physics.js`、`levels.js`：原有物理逻辑与三关。
- `build.py`：合并成一个 HTML。
- `serve.py`：仅用于本机或可信局域网试玩。
- `tests/`：物理测试、浏览器测试、结果 JSON 和截图。

```sh
python3 build.py contraption-lab-mobile.html
node tests/physics.test.cjs
python3 tests/browser_smoke.py
python3 tests/mobile_smoke.py
```

游戏运行不需要 Node 或 Python。测试脚本需要开发者另行具备 Node、Python Playwright 和 Chromium；默认 Chromium 路径为 `/usr/bin/chromium`，其他系统需调整测试脚本的路径。

## 本次验证与未验证项

测试环境为容器中的 Chromium，无真实手机连接。手机交互测试使用浏览器协议发送触摸事件，不是把鼠标拖动冒充多指操作。

验证了 12 种视口：320×568、360×640、375×667、390×844、412×915、430×932、568×320、667×375、844×390、932×430、768×1024、1440×900。检查了横向溢出、主要触控目标尺寸、固定播放控制和横竖屏布局。

验证了点选放置、触摸拖动、取消拖动回滚、长按旋转及单步撤销、双指缩放、空白拖动平移、待放置时捏合不误放、旋转屏幕时回滚未提交拖动、菜单、专注视图、同一大按钮开始/暂停/继续、慢放、三关示例和存档序列化。另有桌面回归以及 12 组物理测试（包含 250 个随机布局）。

测试中的网页错误为 0；单文件启动及游戏交互未请求网络资源。详见 `tests/mobile-results.json`、`tests/browser-results.json` 和 `tests/physics-results.json`。

**未验证：真实 iPhone/Android 硬件、Safari/WebKit、系统刘海与浏览器地址栏的真实动态行为、文件打开后的磁盘存档持久性、用户家中局域网和在线部署。** 容器浏览器的导航策略阻止实际 `file://` 导航，因此测试采用离线 `set_content`，存档往返使用内存 Web Storage 适配器。安全区采用 CSS `env()` 留白，但模拟视口不能代替真机验收。
