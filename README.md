# 造啥都行 · Contraption Lab v0.4.1

V0.4.1 是 V0.4 的手机镜头修正版：

- 竖屏编辑不再固定 1.55×，会按当前关卡自动计算最佳倍率。
- 初始取景优先保证起点、终点与底部玩法区域可见，避免左右被裁掉。
- 固定地形、终点底座和“下落区”仍贴在场景最底部。
- “全景”按钮会重新计算适合当前关卡的最佳取景。
- 实验开始后继续自动跟随小球；靠近左右边缘时会更早平移镜头。
- 接近终点时自动缩小一点，把小球和终点一起纳入画面。
- 左下角手势提示上移，不再压住底部下落区。
- PWA 离线缓存已升级为 `v0.4.1`。

## GitHub Pages 更新

把本目录全部文件上传到仓库根目录并覆盖旧版：

- `index.html`
