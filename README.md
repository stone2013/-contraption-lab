# 造啥都行 · V0.8.0「挑战工坊」

V0.8 新增 07–12 六个机械挑战，总关卡数为 12；同时取消全部关卡的零件数量限制。

## 新关卡

07 越过断层：动力小车。
08 穿过风洞：弹簧与气流。
09 焊住它：可断焊接桥。
10 接住再转：偏心转轴。
11 晃晃吊桥：柔性绳与受力。
12 终极快递：综合机械。

## 无限零件

关卡不再出现“零件已满”，放置、连接、蓝图读取都不受 `budget` 阻止。界面只显示当前零件数量。大量零件会增加物理计算负担，因此在 120 个零件后只提示性能风险，不会限制继续建造。

## GitHub Pages 更新

将 PWA 包中的 `index.html`、`manifest.webmanifest`、`sw.js` 和三个图标覆盖旧文件。版本缓存为 V0.8.0。
