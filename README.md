# 造啥都行 · V0.5.0「机械时代」

在 V0.4.1 的手机布局与镜头基础上增加可运动的机械结构。游戏逻辑、绘制和物理代码全部内嵌在 index.html 中，不依赖 CDN、字体服务、账号或付费 API。

## 马上试玩

进入游戏后，在关卡栏向左滑动，选择 **04 造辆车**，点 **看示例 → 开始实验**。自由改造请先点“返回编辑”。

原三关保留。新增：

| 关卡 | 示例机制 |
| --- | --- |
| 04 造辆车 | 动态车身 + 两只电机轮 + 两个转轴；小车从后面推球进筐。 |
| 05 转起来 | 一块动态木板绕固定转轴倾斜，落到支撑上成为坡道。 |
| 06 吊起来 | 两根绳子悬挂一块动态木板，给小球搭悬空路线。 |

## 机械零件怎么用

**木板**：放置或选中木板，在下方设置选择“固定 / 动态”。动态木板会下落、碰撞、受力和旋转。带“动”标记的木板是动态件。

**轮子**：零件箱切到“机械”，选轮子并点画布放置。可以调整半径，选择自由轮、左转电机或右转电机。电机只有在轮子连接转轴时才会驱动。点轮胎边缘选中轮子；已连接的轴心有独立选择区域。

**转轴**：选“转轴”，先点轮子或动态木板，再点另一个零件。转轴位于第一次点选的位置，两零件连接在同一点，仍能相对旋转。第二次点空白处，则把第一点钉在场景上。点轴心可以选择并删除转轴。

**绳子**：选“绳子”，依次点两个端点。点零件会附着到该零件；点空白处是固定挂点。至少一端连接零件。选中绳子可以调整最大长度；松绳不施加推力。

**整组移动**：默认一起移动或旋转由转轴连接的组件，方便调整整辆车。关闭后可单独调整零件。选中实体后“拆除连接”会删除与它相连的转轴和绳子；删除实体也会删除相关连接。以上操作可撤销。

触屏保留双指缩放、空白处平移、长按角度按钮、暂停、慢放与自动跟球。电脑键位：1–6 选零件，Q/E 旋转，Delete 删除，空格开始/暂停，R 返回编辑，Ctrl/Command+Z 撤销。

## 上传到已存在的 GitHub Pages

解压后把 **文件本身** 放到目前发布游戏的目录，与旧 index.html 同一层。不要上传 ZIP 文件来代替解压，也不要额外套一层目录。

需要一起更新的运行文件是 `index.html`、`sw.js`、`manifest.webmanifest`、`icon-180.png`、`icon-192.png`、`icon-512.png`。README.md 可同时上传。保留仓库原有 CNAME 等其他配置文件，不需要删除仓库。

如果你目前使用仓库根目录发布，就覆盖根目录同名文件；如果 Pages 使用 /docs，就覆盖该目录。GitHub Pages 的发布入口需要位于发布来源目录的顶层。[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

等待 Pages 部署完成，再联网打开原来的游戏地址。页头会显示 **V0.5**，右上角“⋯ → 检查更新”显示完整版本 **V0.5.0**。

已经安装的主屏幕应用不保证关闭重开一次就立即更新。如果仍是旧版：确认 Pages 部署完成，先在浏览器联网重新加载原地址，再关闭并重开主屏幕应用。V0.5 进入后可通过“检查更新”检查服务器的新版本。不要为了刷新随意清除网站数据，以免丢失本机布局。

## PWA 与存档

离线缓存包含游戏入口、清单和三个图标。首次安装或更新需要联网、正确的 HTTPS/localhost 环境及完整文件；缓存成功后设计为可离线再次打开。直接用 file:// 打开单 HTML 可以玩，但不是完整 PWA 安装测试。Service Worker 的默认作用范围是其文件所在目录，安装阶段负责缓存资源。[MDN 官方说明](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)

缓存按项目路径隔离，只清理同一项目的新式旧版本缓存；不会清空其他项目的缓存。更新不会自动打断正在运行的实验。

本机存档键继续使用 `contraption-lab-v1`，兼容原三关的布局和通关记录。首次遇到已有存档时，会尝试保存一份 `contraption-lab-v1-backup-v041` 备份。没有云同步；不同域名、路径部署方式、浏览器或系统的数据策略可能影响存档可用性。

## 本版物理范围

这是游戏化的二维机械原型，不是工程仿真。木板可动态，轮子可滚动，转轴允许相对转动，绳子只拉不推。弹簧和风扇仍固定在场景中。绳子没有质量，不与地形缠绕，没有断裂或切绳。转轴连接的组件内部关闭自碰撞，仍与小球和地形发生碰撞。

纯固定机关布局使用原 V0.4.1 物理核心，以保留旧方案行为；加入轮子、连接或动态木板后会切换到新刚体求解器，弹跳和摩擦表现可能略有差异。大量相互重叠或极短绳索可能导致不稳定，需要调整初始布局。

## 验证范围

本次通过：20 项 Node 物理测试、25 项 Chromium 浏览器测试（含 12 种视口）、10 项缓存逻辑单元测试。六关示例均可通关；涵盖真实模拟触摸事件、两步连接、组拖拽/旋转、撤销、暂停和横竖屏切换。

**未进行真实 iPhone / Android 设备测试，也未在你的线上站点验证发布。** 浏览器测试采用 set_content 本地页面；存档迁移使用 Storage mock，缓存测试使用 CacheStorage/fetch mock，不应等同于真实 Safari PWA 安装、升级及离线验证。完整测试脚本和逐项结果见独立源码包。
