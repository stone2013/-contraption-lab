# 造啥都行 · V0.7.0「结构工坊」

V0.7 把游戏从“会动、会断”继续推进到“能看懂结构为什么坏”。现在可以焊接组件、查看应力、让木板或弹簧在过载时真正损坏，还可以保存蓝图和整组复制机械结构。

## 新功能

### 焊点

在「机械」零件箱中选择 **焊点**，先点一个动态零件，再点另一个零件；第二次点空白场景则把它焊到世界。焊点会锁定连接位置与相对角度，因此适合做刚性车架、支架和固定摆臂。

焊点也会过载。和绳子、转轴一样，可以设置 **脆 / 标准 / 强韧**，受力过大时会崩开。

### 应力热图

实验中可打开 **应力** 显示。结构越接近承载极限，提示越明显。它是游戏化反馈，用来判断“哪里快坏了”，不是工程分析工具。

### 木板和弹簧会损坏

动态木板受到猛烈撞击时可能从受力位置断成两段；动态弹簧严重过载后会损坏，并停止主动弹射。强度可在零件设置里调整。

断裂和损坏只存在于本轮实验。点击「返回编辑」后，编辑布局仍保持完整。

### 蓝图仓库

主菜单加入 A / B / C 三个蓝图槽。可以把当前关卡和搭建布局保存进去，之后从任意关卡读回。蓝图数据继续保存在浏览器本地存档中。

### 整组复制

选中属于机械组件的零件后，可以复制整组。通过转轴或焊点连接的结构会一起复制，连接关系也会保留；一次撤销即可撤回整组复制。

## 物理范围

这是游戏化二维物理，不用于工程计算。应力和断裂阈值是玩法参数，不对应真实材料强度。绳子仍不会缠绕地形或模拟绕桩摩擦；极端重叠、超短连接或异常高速结构仍可能出现夸张效果。
